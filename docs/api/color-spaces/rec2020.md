# Rec.2020

![Rec.2020 Illustration](../../images/space/rec2020.svg)

An ultra-wide gamut color space defined for Ultra High Definition Television (UHDTV). It covers nearly all colors visible to the human eye, far exceeding both sRGB and Display P3.

## Usage

```php
use PhpColor\Color\Rec2020Color;

// Create from components (0.0 to 1.0)
$color = new Rec2020Color(0.5, 1.0, 0.2);

// Convert any color to Rec.2020
$rec = $otherColor->to('rec2020');
```

## Advanced

### Scientific Accuracy
Rec.2020 is designed for the future of broadcast and cinema. It uses a specific piecewise gamma transfer function (approximately 2.2) and is typically used in HDR pipelines.

### Comparison
| Space | Visible Gamut Coverage |
| :--- | :--- |
| **sRGB** | ~35% |
| **Display P3** | ~45% |
| **Rec.2020** | **~75%** |

## Examples

### Interfacing with HDR Pipelines
Use Rec.2020 as a high-precision storage format for color data that needs to be preserved across multiple transformations.

```php
$color = Color::parse($input);
$processed = $color->to('rec2020')->lighten(0.05)->saturate(0.1);
```

### Future-Proofing CSS
Generate CSS that targets high-end monitors supporting the Rec.2020 gamut.

```php
echo $color->toCss('rec2020'); // color(rec2020 0.5 1 0.2)
```
